# Lockerpirate

**Locker Pirate** is a collection of scripts I used while testing and reverse engineering the Amazon Locker BLE protocol.

It includes:

* **Locker Pirate Client** — emulates the mobile app.
* **Locker Pirate Server** — emulates the locker.

These scripts are published largely **as I used them during the research**. They contain commented-out code, hardcoded values, debugging logic, and experiment-specific changes. They are **not intended to be a polished tool or to work out of the box**.

The purpose of this repository is simply to show the types of testing, emulation, and protocol reversing I performed during the research.
